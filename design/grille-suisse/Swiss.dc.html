Études de cas

03 / problème → solution → impact
01

WeSave — migration Vue 3 & design system

Vue 3 Pinia Pinia Colada Storybook MCP
[ capture — WeSave ]
Problème

Une application de conseil financier multi-marques en Vue 2, bâtie sur un kit UI (vue-material) incompatible avec Vue 3.

Solution

Vuex → Pinia, Pinia Colada pour le cache serveur, remplacement des composants par le design system wesave-components.

Impact

Des agents de code branchés sur Storybook via MCP vérifient les vraies props du design system ; périmètre UI ré-estimé de 30 à 14 jours.

02

Forenlyst — authenticité des médias

Next.js NestJS Python Microservices Crypto
[ capture — Forenlyst ]
Problème

La prolifération des deepfakes rend difficile la vérification de l'authenticité des contenus visuels.

Solution

Détection de deepfakes couplée à une certification forensique, résultats signés cryptographiquement.

Impact

Authentification fiable des médias et traçabilité des analyses, pour des usages professionnels et juridiques.

03

trimly — coût des agents IA

TypeScript Node.js CLI npm
[ capture — terminal trimly ]
Problème

Difficile de suivre la consommation de tokens — donc les coûts — en usage quotidien de Claude Code.

Solution

CLI open source qui mesure, agrège et affiche la consommation en temps réel, plus une API réutilisable : @trimly/core.

Impact

Visibilité immédiate sur les coûts ; publié sur npm sous licence Apache-2.0.
